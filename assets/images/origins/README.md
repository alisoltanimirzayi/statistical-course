# Era 01 image assets

This folder contains historical visuals used by the full lessons for **Counting the World**. Do not reuse an asset in a new context without checking its linked source and stated rights.

| File | Lesson use | Source and status |
| --- | --- | --- |
| `../census-package/girsu-barley-rations.jpg` | Cuneiform administrative record | British Museum object BM 102081, via [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Issue_of_barley_rations.JPG); public domain image. |
| `rates-muqaddimah-manuscript.jpg` | Historical anchor for population patterns | Atıf Efendi manuscript, via [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Ibn_khaldun_writting-ms.jpg); public domain in Egypt. This is not presented as the invention of rates. |
| `cardano-portrait-engraving.jpg` | Portrait of Gerolamo Cardano | Unknown artist, before 1906, via [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Hieronimus_Cardanus.jpg); public domain. |
| `chance-liber-de-ludo-aleae.png` | Source image for Cardano lesson | Scan supplied by [Federica e-learning](https://lms.federica.eu/mod/book/tool/print/index.php?id=13053). The 1663 work is public domain; verify image-specific reuse terms before commercial redistribution. |
| `chance-liber-de-ludo-aleae.pdf` | High-resolution 1663 source scan | Downloaded from [Zenodo record 20722200](https://zenodo.org/records/20722200). Retained as a research/source file, not loaded by the site. |

No identified proposer exists for the census lesson. No reliable contemporary likeness is used for the rates lesson; the lesson intentionally avoids presenting a later artwork or statue as an authentic portrait.

The former `census-barley-rations.jpg` and `chance-cardano-portrait.jpg` copies were byte-identical to the canonical files listed above and were removed during cleanup. The canonical image bytes and source credits are unchanged.
